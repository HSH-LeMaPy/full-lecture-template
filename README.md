# Full Lecture Template

Das **Full Lecture Template** ist ein Quarto-basiertes Template zur Erstellung und Bereitstellung von Lehrmaterial in verschiedenen Formaten. Diese lauten:

* eine Website für die Lehrveranstaltung,
* Präsentationsfolien,
* PDF-Dokumente,
* Jupyter Notebooks,
* Aufgabenblätter und Lösungen,
* Begleitdokumente und Cheatsheets.

Es ist primär für Naturwissenschaftliche Lehrveranstaltungen gedacht, die insbesondere mit Python arbeiten.
